Blog REST API

Full-featured blog API with JWT authentication, pagination, filtering, and search.

⚡ Quick Start

1. Get a JWT token:

POST /api/auth/token/
{
  "username": "your_user",
  "password": "your_pass"
}

2. Use the token in requests:

GET /api/posts/
Authorization: Bearer <your_access_token>
